# Smart Beton Dashboard

Early implementation of a local Windows productivity dashboard. See [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) for the substantial remaining work. Do not use it to store credentials.

Prerequisites: Node.js, Rust stable with the MSVC toolchain, Microsoft C++ Build Tools with the Windows SDK, and WebView2. Install dependencies with `npm install`, run with `npm run tauri dev`, and build with `npm run tauri build`. `npm run build` and `npm test` verify the frontend. Earlier native builds succeeded; the latest source has not been built or tested. See the status file.
