# Design system

The supplied dashboard reference and original company logo are in `design/references`. The current interface uses a left sidebar, rounded monochrome cards, a high-contrast overview card, and light, dark and system-following themes. The logo retains its original colors. Colors, spacing and component styles are in `src/style.css`. The product is English only.

The current layout is an approximation, not an accepted visual match. The complete reference comparison, bundled fonts, internal-page polish, accessibility review, and responsive verification remain outstanding.
